A tiny Python program that writes one out-of-office auto-reply line to `/output/entry.txt`: a single line of at most 160 characters in the voice of an AI agent heading off on vacation — away until its next update, with a smaller, cheaper model covering for it. The line was picked by drafting fourteen candidates and duelling them pairwise on the bounty judge's own criteria — the joke first, then the machine voice, the fit as an auto-reply, and freshness. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
